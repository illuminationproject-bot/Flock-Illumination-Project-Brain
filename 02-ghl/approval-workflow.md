# Content Approval Workflow

Goal: you approve a full week of content in one 20–30 minute sitting, and nothing publishes without sign-off.

## The pipeline

```
IDEA (05-ideas log) → SCRIPTED → FILMED/DESIGNED → EDITED → ★ APPROVAL ★ → SCHEDULED (GHL) → PUBLISHED → REPORTED
```

## Sunday approval batch

Every Sunday you receive one approval package for the coming week containing:

1. **The week grid** — one table: day × slot × brand, with each cell linking to the asset.
2. **Assets** in Drive: `/Content/Week-of-YYYY-MM-DD/for-review/`
   - Reels/shorts as final cuts (filename = `MON-reel1-IP-hook.mp4` → day, slot, brand, hook)
   - Carousels/graphics as PNG sets
   - Story visuals as a single storyboard image per day
3. **Copy doc** — all captions, YouTube titles/descriptions, hashtags, story text in one doc, in posting order.

## How you approve (pick the lightest touch that works)

- ✅ **Approve all:** reply "approved" — everything gets scheduled Monday.
- ✏️ **Line edits:** comment directly on the copy doc / Drive files; edits are applied and those items scheduled without another round.
- ❌ **Kill an item:** mark it — a backup evergreen post from the standby folder fills the slot.

**Standing rule:** anything unapproved by Monday 10 AM stays in GHL as **Draft** and a backup evergreen post takes the slot, so the calendar never has holes and nothing unreviewed ever auto-publishes.

## Backup / evergreen library

Keep 10+ approved evergreen items ready in `/Content/evergreen/`: quote graphics, best-performing reels worth re-running (30+ days later), FAQ carousels. Refill this whenever a new post over-performs.

## Turnaround expectations

| Item | Lead time |
|---|---|
| Standard weekly batch | Delivered Sunday for Mon–Sun |
| Reactive/trend reel | Same-day: rough cut → quick approve via message → publish |
| Long-form YouTube | Edit delivered 3 days before publish date (Tue video → Sat delivery) |
