# Editor Creative Brief — Template (00-BRIEF.md in every package)

> The brief gives **goalposts, not scripts.** It tells the editor what the piece must
> accomplish and where the hard lines are — everything else is theirs. AI mockups and rough
> cuts in the package are a floor, not a ceiling: *beat them, don't match them.*

---

## 1. The package at a glance

| Field | Fill in |
|---|---|
| Pillar / recording | e.g. `2026-07-08 Flock Talk — "Creative burnout in worship teams"` |
| Thesis (one sentence) | What the viewer should walk away believing |
| Audience + emotional target | e.g. "worship pastor, 25–35, feeling creatively dry → seen, then equipped" |
| Deliverables | 1 main + N chapters + N shorts (list with working titles) |
| Priority order | Which piece matters most if time runs short |
| Deadline | Per deliverable |
| CTA | One per piece, from the CTA doc |
| TJ's voice note | Link — listen before opening a timeline |

## 2. LOCKED — non-negotiables (short list, hard lines)

1. Brand fonts, colors, logo files — exactly as in Brand Guide / PSD templates
2. Captions on every piece; word-accurate on names, faith vocabulary, lyrics (see Edit Map flags)
3. Hook lands in the first 3 seconds — no slow intros, no "hey guys"
4. One CTA per piece, as specified; music content: CTA in caption/bio only, never on-screen
5. IP music only (no third-party tracks); -20dB under talk content, never under teaching
6. Grade stays inside the two brand modes (Bright & Clean / Moody & Cinematic) — *which* mode
   and how far to push it is the editor's call unless the brief pins it
7. Export specs + file naming per Editor SOP; platform safe areas respected
8. Nothing in the LOCKED list gets "creatively reinterpreted"

## 3. FREE — the editor's domain (deliberately long list)

Pacing and rhythm · cut points and jump-cut style · zoom/punch-in choices · caption animation
and emphasis styling (within brand fonts/colors) · motion graphics and B-roll treatment ·
sound design, risers, whooshes, silence · grade expression within the chosen mode · thumbnail
final composition, expression frame, text placement · end-card motion · which hook variant
(spoken vs text-led) opens each short · anything not in the LOCKED list.

If a FREE choice would break a LOCKED rule, LOCKED wins. If a genuinely better idea requires
bending a LOCKED rule, pitch it at Gate 1 with a one-line rationale — don't ship it silently.

## 7. Gates

- **Gate 1 (24h):** one Loom ≤90 sec — title direction, thumb direction, grade mode, pacing
  intent for the main video. Wait for green-light voice note before deep polish.
- **Gate 2 (delivery):** QC checklist (Editor SOP §5) self-run before handoff.
- Between gates: no notes from TJ, no check-ins required. The window is yours.
